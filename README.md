
# Pikop — Responsive Website

A responsive marketing website for Pikop, a delivery and shopping platform. The website introduces the service, explains its main offerings, and directs visitors to the mobile application.

This project is included in my software development portfolio with permission from the client.

## Features

- Responsive layout for mobile and desktop screens
- Service sections for dispatch, food, groceries, and marketplace shopping
- Navigation menu and interactive FAQ
- Mobile application download links
- Business and fulfiller information
- Contact links and supporting policy pages
- Optimized logo and visual assets
- Accessibility and performance testing with Lighthouse

## Built With

- HTML5
- CSS3
- Vanilla JavaScript
- Git and GitHub
- Chrome Lighthouse

## Run Locally

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using VS Code Live Server.
4. Test the website in your browser.

No package installation or build step is required for the current static website.
